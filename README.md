<h2>Prognostic lncRNA Signature in High-Grade Serous Ovarian Cancer</h2>

| # | Project | Question | Result |
|---|---|---|---|
| 01 | [Differential expression](https://github.com/himanshuguptaofficial/Bioinformatics-Developmental-Projects/tree/main/01-differential-expression) | Which lncRNAs differ between resistant and sensitive patients? | 554 at raw p < 0.05, none survive FDR correction |
| 02 | [Survival risk score](https://github.com/himanshuguptaofficial/Bioinformatics-Developmental-Projects/tree/main/02-survival-risk-score) | Does a composite of five lncRNAs stratify survival? |Apparent log-rank p = 1.2 × 10⁻⁹, roughly a 2-year median survival gap |

| 04 | [Pathway enrichment](https://github.com/himanshuguptaofficial/Bioinformatics-Developmental-Projects/tree/main/04-pathway-enrichment) | Which biological pathways are associated with the lncRNA signature? | Overwhelmingly immune, cytokine and T-cell signaling |
